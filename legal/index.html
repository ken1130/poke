6. 隱私權政策

6.1 我們收集哪些資料

  • 訪客（不登入）：你的存檔與設定只存在你自己的瀏覽器（localStorage）中，不會傳到我們的伺服器。
  • 建立帳號時：你的玩家暱稱，以及遊戲存檔（收藏、金幣、升級、統計資料等）。
  • 使用 Google 登入時：Google Firebase 會保存你的 Google 電子郵件地址以辨識帳號。這個地址不會顯示給其他玩家。
  • 好友與排行榜：你的暱稱（對其他玩家公開）、好友名單、上線狀態，以及最佳紀錄（含暱稱與使用的寶可夢）。

我們不收集你的真實姓名、地址、電話、付款資料或精確位置，也不使用任何廣告、追蹤或分析工具。

6.2 使用目的

上述資料只用來提供遊戲功能：保存與同步你的進度、顯示好友與排行榜、讓多人連線運作。我們不會出售、出租或分享你的資料給任何第三方用於行銷或其他目的。

6.3 服務提供者與資料存放地點

  • Google Firebase（帳號驗證、雲端存檔、好友、排行榜）：資料存放於 Google 的伺服器，可能位於你所在國家或地區以外，並受 Google 隱私權政策 規範。
  • Cloudflare（多人連線中繼）：當你與隊友無法直接連線時，遊戲連線資料會經由 Cloudflare 的中繼伺服器轉送，只用於即時轉送，我們不保存這些內容。
  • GitHub Pages（網站託管）：GitHub 可能依其政策記錄一般的伺服器存取紀錄（例如 IP 位址）。

6.4 多人連線與 IP 位址

多人遊戲時，你的瀏覽器會直接與隊友的瀏覽器連線（就像視訊通話一樣），因此其他玩家在技術上可能看到你的 IP 位址。請只和你認識的人一起連線遊玩。

6.5 Cookie 與本機儲存

我們使用瀏覽器的本機儲存（localStorage、IndexedDB）來保存存檔、設定與登入狀態，這些是遊戲運作所必需的。我們不使用廣告或追蹤用 Cookie。

6.6 保存期間與刪除

你的帳號資料會保存到你刪除帳號為止。你可以隨時在遊戲中的「法律聲明」視窗按下「刪除我的帳號和存檔」，系統會一併刪除你的帳號、存檔、暱稱、好友與排行紀錄。若帳號已無法登入，也可透過 GitHub Issues 請求協助（請勿在公開留言中貼出你的電子郵件）。

6.7 你的權利
