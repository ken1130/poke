# PokéSurvivor 繁體中文版（個人用途）

這是 [PokéSurvivor](https://github.com/JPTER78)（原作者：JPTER78）的**個人修改版**，
僅供本人與朋友私下遊玩，**非商業用途、不收取任何費用、不接受贊助或廣告**。

## 這個版本改了什麼

- 介面與寶可夢名稱翻譯為繁體中文
- 不需註冊就能玩，進度先存在玩家自己的瀏覽器；想保存到雲端時，可在右上角「綁定 Google」，進度會存到本專案自己的 Firebase（免費方案），換手機或電腦用同一個 Google 帳號綁定即可取回
- 可自訂暱稱（設定 → 帳號）
- 和朋友一起玩：建立房間取得 6 碼邀請碼，朋友輸入代碼加入，房主可選「組隊」或「PK」（最多 4 人，需綁定 Google）
- 移除好友與排行榜等線上功能
- 遊戲模式：每日挑戰（同一天大家同一張地圖）、傳說連戰、異色模式、頭目模式、極限模式、自訂難度
- 強化新增「回復封鎖」（降低敵人治療量）與一鍵強化
- 存檔匯出／匯入（設定 → 帳號），可在電腦和手機之間搬移進度
- 加入個人娛樂用的密技功能（主選單或暫停畫面的「金手指」）

## 怎麼玩

用瀏覽器打開網頁即可。沒綁定 Google 前，進度只存在該瀏覽器，換裝置或清除瀏覽器資料後會消失；綁定後會存到雲端。

在 LINE 等 App 裡開啟時，Google 不允許登入，請改用 Chrome 或 Safari 開啟再綁定。

| 按鍵 | 動作 |
|---|---|
| `W` `A` `S` `D` / 方向鍵 | 移動 |
| `1` `2` `3` `4` | 切換招式 |
| `Q` / `E` | 循環切換招式 |
| `Esc` / `P` | 暫停 |

手機請橫向持握，手指拖曳即可移動。
